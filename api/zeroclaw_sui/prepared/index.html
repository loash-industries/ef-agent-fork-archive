The wire payload produced by a keyless transaction builder.

An external service (today: the Trinary Exchange MCP server) constructs a programmable transaction and returns it unsigned. This module models that response. Nothing here is trusted: the fields exist so they can be cross-checked against the transaction bytes, not so they can be believed.
