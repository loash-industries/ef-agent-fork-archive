Sui transaction verification for ZeroClaw.

ZeroClaw agents obtain transactions from builders that deliberately hold no key: the builder assembles a programmable transaction and returns it unsigned, and the agent decides whether to commit its key to it. That split only buys safety if the deciding half re-derives its facts from the transaction bytes, so this crate treats the builder’s own description as a claim to be checked rather than as information.

use std::str::FromStr;
use sui_sdk_types::Address;
use zeroclaw_sui::{PreparedTransaction, SubmitPolicy, verify};

let me = Address::from_str(
    "0x1111111111111111111111111111111111111111111111111111111111111111",
)?;
let policy = SubmitPolicy::deny_all(me)
    .allow_target("0x2::coin::zero".parse()?)
    .allow_spend("currency", "CRED", 1_000_000);

let prepared = PreparedTransaction::from_json(r#"{ "...": "from the builder" }"#)?;
let verified = verify(&prepared, &policy, 1_789_000_000_000)?;
// `verified.kind` is now safe to wrap with gas data and sign.
