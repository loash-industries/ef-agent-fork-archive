Module signer 

Expand description

The agent’s key, and the only place it is used.

Per ADR-013, a non-encryption consumer must not silently reuse ZeroClaw’s master encryption key. This type therefore takes key material explicitly from its caller and reaches for no ambient source of its own: it never reads .secret_key, never touches SecretStore, and derives nothing from the master key. Choosing where an agent’s wallet key actually lives is a custody decision that ADR-013 leaves open, and this crate deliberately does not prejudge it.

Signing itself is delegated to sui-crypto. Sui signs a digest over an intent-prefixed message, and a hand-rolled version that got the prefix wrong would still verify against its own public key while being rejected on chain — a failure that testing in isolation cannot catch.
