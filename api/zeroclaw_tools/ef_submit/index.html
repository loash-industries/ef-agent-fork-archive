Module ef_submit 

Expand description

ef_submit — commit the agent’s key to a transaction it did not build.

This is deliberately a native tool rather than one reached over MCP. ZeroClaw auto-admits any runtime-discovered MCP tool (any name containing __) into a non-empty allowed_tools list, so an MCP-hosted version of this capability would bypass the very allow-list an operator would reach for to constrain it. As a native tool it is gated normally, and it declares ToolOperation::Act so autonomy level and approval routing apply.

The tool holds the key; it does not decide what is safe. Every judgement about the transaction is made by zeroclaw_sui::verify against a policy built from configuration, from the transaction bytes rather than from the builder’s description of them.
